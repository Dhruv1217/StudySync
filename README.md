# StudySync

## Description
StudySync is a Python-based Student Productivity Management System.

## Features
- Create Account
- Login
- Change Password
- Task Management (CRUD)
- Attendance Calculator
- CGPA Calculator
- Study Progress
- Weekly Report

## Technologies Used
- Python
- OOP (Object-Oriented Programming)
- JSON
- File Handling
